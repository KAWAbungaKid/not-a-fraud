- **Drop sets.** Tick a set, then tap **↓** next to it: a drop set goes under it (~20 % lighter, to failure). Tap ↓ again for another drop. Rest starts after the last drop. Drops don't count as extra hard sets or toward your max.
- **Either / or exercises.** In a program day, "+ or another exercise" on any exercise. In the workout, chips under the name let you pick which one today; next time it starts with whatever you picked last.
- **Equipment per exercise** (Exercise details): barbell, dumbbells, weight stack / cable, plate-loaded machine, plate-loaded pulley (with its ratio, e.g. 2:1), bodyweight. Plate math only shows where plates go: none for cables and stacks; dumbbells say "each hand"; a pulley says what to load on the pin for the weight the handle feels. Guessed from the name until you set it.

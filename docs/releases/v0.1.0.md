First build. Install the APK on the phone and the MSI on the PC; setup steps are in docs/SETUP.md.

**Phone**
- Blocking with earn-to-unlock: focus-app minutes and logged task minutes become credits; spend 5/10/15/30 to open a blocked app. Emergency unlock: 60 s wait + typed phrase, 3 per day.
- Always-on "do this now" notification with Start / Done / Replan, updated at each block boundary.
- Day plan from your anchors (classes, lifts, market, research Saturdays, date night, Sunday reset), phone calendar and tasks, scored with the web app's engine. Rough day (under 6 h sleep or marked by hand) = lighter plan, 4 h focus cap.
- Escalating nudges while an unlocked time-sink is open; gentler and shorter on rough days; none during protected time.
- Snapchat messages mirrored into the Inbox tab, reply inline when Snapchat allows it.
- Screen time per app, sleep / workouts / steps from Health Connect.
- Midweek ideas get captured and wait for the Friday craft block.
- Watchdog notification if Android kills the guard.
- Seeded with the web app's projects and tasks.

**Windows**
- Tray app: current block, plan, up next, start/stop sessions.
- Tracks the program in front (and YouTube etc. by window title), idle-aware; nudges on distractions, optional minimize.

**Not yet:** sync between phone and PC (Firebase), stats/XP layer.

Install over 0.3 like before.

**Tests come from your calendar now**
- New calendar type: **Tests** (More → Google Calendar). Every entry is fixed time in the plan *and* gets a study task (6 h by default, starting up to 10 days before). Move the test in Google Calendar and the study deadline moves; delete it and untouched studying goes away. Calendars with "test" or "exam" in the name start as Tests.
- The exam studying that was imported from the old web app, the auto-made exam tasks from 0.3, and the built-in ME 3411 final are removed (anything you'd already logged time on is kept). No more doubles.
- Spotting exams by title in normal Events calendars is now off by default (switch in the same screen).
- Study hours per test and how early to start are in the same screen.

**Blocking**
- The block screen shows instantly again (0.3 waited 0.7 s for a notification tap to land).
- **Reply windows are more reliable.** Opening Snapchat any way within 15 minutes of a new message is a free 5-minute reply window, once per message. Tapping the notification still works too, and if the block screen got there first it now closes itself and opens Snapchat. Story posts and streak reminders don't count as messages.

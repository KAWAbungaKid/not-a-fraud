First build of the workout app (separate app, installs next to Not a Fraud).

- Log workouts set by set (weight / reps / RPE), timed holds with a Go/Stop stopwatch, rest timer.
- Your spreadsheet as the starting preset: types, RPE chart, maxes, 12-week cycle (starts at Week 2 · Block 1).
- New split: Push / Pull / Legs (your minimum), then Chest & Back / Shoulders & Arms / Legs 2.
- Suggests today's workout, puts skipped days first, moves the program week on when you hit your minimum.
- e1RM updated every workout; training max = best of the last 6 weeks.
- Short mode and Injured mode.
- Edit exercises, types and programs; duplicate presets.
- Not a Fraud can read your week (minimum, risk, today's pick) — the Not a Fraud side comes next.

Install over 0.1.3 (data stays).

- **Import from Hevy:** Settings → Import from Hevy → pick the CSV you exported from Hevy. Workouts, sets and e1RM history come in; exercises match yours by name, and new ones are created (give them a type in Exercises). Importing the same file twice adds nothing.
- **Warm-ups and plates:** an exercise's ⋮ menu → "Add warm-up sets" (bar, ~40 %, ~60 %, ~80 %). Every barbell exercise shows "Plates for 225: 2×45 per side". Set your bar and the plates you own in Settings.
- **Rest timer in the notification shade:** the countdown shows in the shade and buzzes when it's over, even with the screen off or the phone in your pocket.
- **Health Connect:** finished workouts are written as strength training (Settings → Health Connect → Allow), so Samsung Health sees them. Not a Fraud doesn't count them as cardio.
- **Edit a finished workout:** History → a workout → "Edit sets". It opens like a running workout; Finish saves it with its original times, Discard leaves it as it was.
- **Supersets:** ⋮ → "Superset with the next exercise". Rest only starts after the last exercise of the pair.
- **Weekly volume:** History shows sets per muscle for each week.
- **Climbing tomorrow:** when Not a Fraud sees a sport tomorrow (a planned climbing session or a calendar entry), today's suggestion avoids the Shoulders & Arms day and says why.

Install over 0.12.1. **Your data and setup don't change**: onboarding only runs on a new install.

**Streak numbers on routine items.** Each item shows how many days in a row you've done it (only counting the days it applies). Weekly-target items like Workout show weeks in a row meeting the target. Today not being done yet doesn't break it; it turns green when it's your best run.

**Ready for other people (first part):**
- **Onboarding** on a new install: name → goals (with how much each matters) → modules → wake-up, bedtime, school / work → a starter routine timed from your day → permissions, each with its own explanation → done. Nothing of yours is in a new install.
- **Modules** (More → Modules): Planner, Routine, Blocking, Stats, Skills. Off = its pages are hidden and it goes silent; nothing is deleted. Turning Blocking or Routine off waits for the morning, like other loosening changes.
- **Page tips:** each page shows a two-line tip the first time it's opened ("Got it" hides it; More → "Show the page tips again").
- Time zone comes from the phone, and the bedtime nudge uses your own wake-up time instead of 5:30.

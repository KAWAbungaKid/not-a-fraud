Install over 0.8.0 like before (data stays). Rollback: reinstall 0.8.0 from the releases page. Also install **Not a Twig 0.2.1** (one new switch, below).

**Not a Twig is connected.** Meals logged in Twig tick the matching routine meal here (Lunch → Lunch, Supper → Supper, "Pre-workout meal" → Twig's Pre-workout slot). While Twig is connected, a linked meal gets loud when *Twig* says it's late, not on this app's clock. Twig's other reminders (water, weigh-in, the clarity / energy check-in) come through the same routine nags, at most two at a time, with an **Open Not a Twig** button. In Twig → Settings, turn off **Show reminders here** so you don't get everything twice (Twig still tells this app what's late). Off switch here: More → Planning → Not a Twig. Edit any meal on the Routine page to link it to a different Twig slot or none.

**How's today** shows Twig's line (clarity, energy, kcal, protein, water, hours since food). A foggy / low check-in (1–2 of 5) counts as a burnout signal, and the suggestion puts the basics first: eat if it's been 5 h+, water if you're well behind, then a daylight walk.

**Sports count as cardio.** With Not a Troglodyte connected, a 20+ minute session on a sport skill (climbing, athletics…) ticks **Cardio** instead of the workout, and Samsung Health exercise ticks Cardio too. They never count toward the workout minimum. Body stat now includes cardio. The seeded "Workout (lift, climb...)" item is now just "Workout". Troglodyte is called by its name everywhere.

**Streaks (new routine type).** Add a routine item and pick type **streak**: it counts as done every day by itself, never nags and has no times. Its row shows days in a row; tap **Broke it** (today or yesterday) when you break it, which resets the count and keeps your best run. Set "days in a row so far" when you add one you've already been keeping.
